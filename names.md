# Brainstormed Project Names

## Concept 1: Core & Essence (Memory Vault & Context Condenser)
- **pith.ai** / **pithy.ai** (Pith means the core, essence, or central structural part of a stem. Perfect for a system that extracts user facts into a Structured JSON Memory Vault and condenses long logs into Topic Cards. 4 letters, simple, available)
- **grit.ai** (Grit means tiny pebbles, or fortitude/focus. 4 letters, easy to say, open)
- **silt.ai** (Fine sand/clay deposited by running water. Represents the accumulation of user memory/facts over time. 4 letters, simple, open)

## Concept 2: Branching & Track Divergence (Visual Canvas & Hot-Swapping)
- **spur.ai** (A branching path or track that diverges from the main line. Direct metaphor for branching conversation streams on a React Flow canvas. 4 letters, simple, easy to say)
- **prune.ai** (Trimming/cutting branches. Direct nod to the Context Condenser and token pruning. Highly recognizable, simple, open)
- **scion.ai** (A shoot or twig cut for grafting. Reflects branching paths and injecting/hot-swapping context. 5 letters, simple, open)
- **verge.ai** (Verge means edge, border, or boundary. Represents the active node boundaries, state edge, and has a strong phonetic link to "merge" in Git. 5 letters, simple)

## Concept 3: Joining & Syncing (IndexedDB & Cloud Sync)
- **weld.ai** (To join or fuse parts together. Reflects state syncing between local IndexedDB, remote Postgres, and Qdrant vector DB. 4 letters, simple, open)
- **hasp.ai** (A metal clasp/lock, representing secure state persistence and syncing. 4 letters, simple, open)
- **plait.ai** (A braid or weave of multiple strands. Represents merging multiple conversation paths together. 5 letters, simple, open)
- **buckle.ai** (To fasten or secure. Represents state binding. 6 letters, simple, open)
